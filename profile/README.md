**NoneLabs VulnHound**는 **"Zero-Cloud, Zero-Cost, Zero-Exposure"** 철학을 바탕으로  
취약점 인텔리전스, 임베디드 RAG, 그리고 비밀 보안 운영(Secret Ops)을 연구·개발하는 오픈소스 보안 R&D 조직입니다.

---

## 🏛️ 조직 핵심 철학 (Core Principles)

* 📦 **Zero-Cloud ($0 Cost)**: 상시 구동 클라우드 인프라나 유료 DB 없이 순수 Go 및 자립형 OCI 컨테이너로 완전 독립 구동.
* ⚡ **Self-Contained Intelligence**: NVD CVE 30만 건과 MITRE CWE 위협 지식을 초경량 양자화 벡터 RAG로 압축 패키징하여 오프라인에서 즉시 제공.
* 🔒 **Zero-Exposure (Stealth Ops)**: 취약점 발견 시 제로데이 무단 노출을 방지하기 위해 **GitHub Security Advisories** 및 **GitLab Confidential Issues/MRs (`-c`)**로 은밀하게 격리 패치.

```
[NoneLabs VulnHound]
         │
         ├─► Community (Free / Open-Source)

         │   • CVE/CWE 벡터 RAG & 방어 가이드
```
